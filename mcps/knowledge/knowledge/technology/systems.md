## High Performance Computing (HPC) System

### HPC Administration

The High Performance Computing system (سامانه پردازش سریع) provides high-speed computational services for research and academic purposes.

### Key Officials and Websites
- **HPC Website**: https://hpc.sharif.ir
- **HPC in Persian**: https://ictc.sharif.ir/سامانه-پردازش-سریع-hpc
- **ICT Center HPC Page**: https://ictc.sharif.ir/%D8%B3%D8%A7%D9%85%D8%A7%D9%86%D9%87-%D9%BE%D8%B1%D8%AF%D8%A7%D8%B2%D8%B4-%D8%B3%D8%B1%DB%8C%D8%B9-hpc

### HPC Capabilities

#### Computing Resources
- **CPU Clusters**: Multi-core processor clusters for general-purpose computing
- **GPU Clusters**: Graphics processing units for parallel computing, machine learning, and simulations
- **Storage Systems**: High-capacity and high-speed storage for research data
- **Interconnect**: High-speed network connections between computing nodes

#### Supported Applications
- **Scientific Simulations**: Finite element analysis, computational fluid dynamics, molecular dynamics
- **Data Analysis**: Large dataset processing, statistical analysis, machine learning
- **Parallel Computing**: MPI, OpenMP, and other parallel programming models
- **Machine Learning**: Deep learning frameworks, neural network training
- **Visualization**: 3D visualization, data visualization, rendering
- **Code Development**: Compilers, debuggers, and development tools for HPC

#### User Access
- **Eligibility**: Faculty, graduate students, and approved researchers
- **Authentication**: Sharif ID login
- **Quotas**: Resource quotas based on user category and project
- **Scheduling**: Job scheduling system for resource allocation
- **Training**: HPC usage training and workshops

#### HPC Services and Features

##### 1. Computation Services
- **Batch Processing**: Job submission and batch processing system
- **Interactive Sessions**: SSH access to compute nodes
- **Development Environment**: Compilers, libraries, and development tools
- **Debugging Tools**: HPC application debugging utilities

##### 2. Data Storage
- **Home Directories**: Personal storage space for users
- **Project Storage**: Shared storage for research projects
- **High-Speed Scratch**: Temporary high-speed storage for computations
- **Backup Systems**: Data backup and recovery systems
- **Long-term Archive**: Permanent storage for research data

##### 3. Software Environment
- **Pre-installed Software**: Common scientific and engineering applications
- **Module System**: Easy software version management
- **Custom Software**: Installation of research-specific software
- **Licensing Management**: Software license administration
- **Environment Modules**: Conda, Conda environments, and module systems

##### 4. Technical Support
- **User Guides**: Documentation and tutorials
- **Training Workshops**: HPC usage training sessions
- **Help Desk**: HPC-specific support desk
- **Consulting**: HPC consulting for project planning and optimization

### HPC Access Process

1. **Account Request**: Submit HPC account request through ICT Center
2. **Approval**: ICT Center and relevant department approval
3. **Authentication**: Sharif ID setup and password configuration
4. **SSH Access**: Secure Shell access to HPC systems
5. **Job Submission**: Job scheduler (SLURM, PBS, or similar) for resource allocation
6. **Resource Monitoring**: Monitor computing usage and quotas
7. **Support Access**: Help desk and consulting for HPC-related issues
